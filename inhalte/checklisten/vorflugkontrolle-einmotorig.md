# Checkliste: Vorflugkontrolle einmotoriges Flugzeug (generisch)

> **Wichtig:** Dies ist eine **generische Lern-Checkliste**. Maßgeblich ist **ausschließlich die Checkliste im Flughandbuch (AFM/POH)** deines Flugzeugs – z. B. DA20 (OE-CBF) oder C172 (OE-DTT) – und die Vorgaben der Flugschule. Reihenfolge und Punkte unterscheiden sich je nach Muster (Hoch-/Tiefdecker, Einspritzer/Vergaser, Verstellpropeller).

## 1. Kabine

- [ ] Dokumente an Bord (siehe [Flugvorbereitung](flugvorbereitung-vfr-oesterreich.md))
- [ ] Bordbuch: offene Beanstandungen, Wartungsintervall
- [ ] Zündung **AUS**, Zündschlüssel abgezogen
- [ ] Hauptschalter **EIN** → Kraftstoffanzeige ablesen, Klappen ausfahren (bei elektrischen Klappen), Lichter prüfen, Stall-Warnung prüfen → Hauptschalter **AUS**
- [ ] Ruder frei und gängig, Steuerschloss entfernt
- [ ] Brandhahn/Tankwahlschalter in richtiger Stellung
- [ ] Feuerlöscher (Prüfdatum), Erste-Hilfe-Kasten, ELT auf ARM
- [ ] Sitze, Gurte, Kanzel/Türen in Ordnung, lose Gegenstände gesichert

## 2. Außen – Rumpf und Leitwerk

- [ ] Beplankung ohne Beulen, Risse, Delaminierung (bei Faserverbund)
- [ ] Antennen fest
- [ ] Statische Druckentnahme frei
- [ ] Höhen- und Seitenleitwerk: Befestigung, Ruder frei, Spiel, Trimmruder, Gegengewichte
- [ ] Ruderanschlüsse und Sicherungen
- [ ] Positions- und Anti-Collision-Licht

## 3. Außen – Tragflächen

- [ ] Querruder und Klappen: Beschläge, Spiel, freie Bewegung
- [ ] Flächenspitze, Positionslicht
- [ ] Vorderkante ohne Beschädigung, **frei von Eis, Schnee, Reif, Insekten**
- [ ] Staurohr (Pitot): Abdeckung entfernt, frei
- [ ] Stall-Warngeber frei
- [ ] Tankdeckel fest, Entlüftung frei
- [ ] **Kraftstoffmenge visuell geprüft** (Peilstab)
- [ ] **Kraftstoffprobe** aus allen Drainstellen: Sorte (Farbe), **kein Wasser**, keine Verunreinigung
- [ ] Verzurrung entfernt

## 4. Außen – Fahrwerk

- [ ] Reifen: Druck (Sicht), Profil, Schnitte, Rutschmarken
- [ ] Federbeine/Bremsen: keine Lecks, Bremsleitungen intakt
- [ ] Radverkleidungen fest, Bugrad/Lenkung in Ordnung
- [ ] Bremsklötze entfernt (vor dem Anlassen)

## 5. Außen – Motor und Propeller

- [ ] **Ölstand** im zulässigen Bereich (POH), Öldeckel fest
- [ ] Motorraum (soweit einsehbar): keine Lecks, lose Teile, Vogelnester; Abgasanlage intakt
- [ ] Cowling fest verschlossen
- [ ] Propeller: keine Kerben/Risse, Spinner fest (**Propeller immer als „scharf“ betrachten!**)
- [ ] Lufteinlass und Luftfilter frei
- [ ] Gascolator/Kraftstofffilter gedraint (falls vorhanden)

## 6. Abschluss

- [ ] Rundgang komplett, alle Abdeckungen verstaut
- [ ] Umgebung frei (Hindernisse, Personen) für das Anlassen
- [ ] Weiter mit der **POH-Checkliste „Before Starting Engine“**
